# Conquista & Comércio — Flutter

## Executar
1. Instale o Flutter SDK.
2. Extraia o ZIP e abra a pasta no VS Code ou Android Studio.
3. No terminal execute `flutter pub get` e `flutter run`.

## Atualizações desta versão
- Interface reorganizada em quatro abas: Mapa, País, Jogadores e Histórico.
- Mapa ilustrado do mundo integrado em `assets/mapa_mundo.png`.
- Painel de turno simplificado e ações organizadas em listas.
- Mantidos sorteio de países, dados, recursos, comércio, alianças, batalhas, melhorias e casas do tabuleiro.

## Observações
O mapa é uma referência visual nesta versão; ainda não possui fronteiras clicáveis nem captura territorial. Mobilização, vitória automática, cumprimento automático das alianças e salvamento de partidas ainda precisam ser implementados. O mapa artístico contém nomes/descrições visuais gerados e deve ser tratado como ilustração; os dados oficiais dos países usados pelo jogo estão no código.
